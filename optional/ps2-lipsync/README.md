# PS2 语音口型补偿

[`ps2-lipsync-adaptive.patch`](ps2-lipsync-adaptive.patch) 保存了澪尽篇 PS2 语音口型补偿的源码差异，基准为 07th-Mod Console Arcs v10.2.0（`3eb3e287`）。补丁中的文件路径沿用该版本程序集导出为 C# 工程后的目录结构。

实时口型计算读取 `ps2/` 下的语音时，先估计每句的有效语音幅度，再为口型判定应用最多两倍的增益。静音、有效采样过少和正常响度的片段可沿用原有判定。语音播放继续使用原录音和音量设置。

将源码差异应用到对应版本的 `SceneController.cs` 后，随 07th-Mod 构建程序集。补丁文件用于源码维护。
