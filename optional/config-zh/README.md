# 设置页汉化

适用于主机篇简体中文补丁 v2.0.0，涵盖设置页标签、选项按钮、分辨率说明和「关闭」按钮。语言选项中的「简体中文」对应主补丁使用的原 `English` 槽位。

关闭游戏后，在本目录双击 `install.cmd`，输入包含 `HigurashiEp04.exe` 的游戏目录。安装器会校验资源版本并备份原文件。启动游戏后，在主菜单选择 `CONFIG` 查看中文设置页。

如需恢复，关闭游戏，把游戏目录下 `HigurashiEp04_Data/sharedassets0.assets.config-zh-backup` 改回 `sharedassets0.assets` 并覆盖当前文件。
